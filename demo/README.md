# goredis 药房

在 `goredis-rebuild` 目录启动：

```bash
go run ./cmd/demo
```

浏览器访问 <http://127.0.0.1:8080>。一个进程同时启动数据库和演示页面，无需另外运行 `go run .`，无需安装前端依赖。

数据库读取当前目录的 `redis.conf`，默认使用 6379 端口。页面默认仅监听本机，端口可以修改：

```bash
go run ./cmd/demo -http 127.0.0.1:8081
```

## 功能

- **执行命令**：滚轮选择 20 条命令，支持上下方向键、搜索和类型筛选；动态填写参数，Enter 执行。SET 支持 NX、EX，多参数命令支持添加或删除参数行。
- **执行结果**：显示返回值、错误信息、耗时和原始 RESP 响应。
- **存储信息**：展示 key、类型、内容和过期时间，支持搜索、筛选、查看详情和手动刷新；页面执行命令后自动更新。
- **命令记录**：当前演示进程保留最近 200 条页面命令，可清空。清空记录不删除数据库内容或日志文件。
- **运行日志**：读取当前目录 `app.log` 的最近内容，支持级别筛选和刷新。
- **AOF 持久化**：读取真实 `appendonly.aof` 的文件大小、同步策略与当前文件中最近 40 条命令；重写后显示的是重写后的文件内容。可通过写入、关闭并重启 Demo、重新查询来展示数据恢复。
- **首页展示**：便当盒布局与毛玻璃卡片；桌面鼠标经过卡片时有轻微三维倾斜和跟随光斑。药房场景固定在后景，前景卡片随页面滚动；系统开启“减少动态效果”时会停用动画。

## 调用关系

```text
页面命令 → HTTP /api/command → RESP/TCP → Handler → Trigger → Executor → KVStore
存储查询 → HTTP /api/storage → Executor 的快照请求 → ForEach → ToCmd → 独立快照
运行日志 → HTTP /api/logs → app.log
命令记录 → HTTP /api/history → 演示服务内存
AOF 视图 → HTTP /api/aof → 当前 appendonly.aof 文件
```

页面不模拟数据库结果，不预置演示数据。存储快照与普通命令在同一 Executor 中串行读取，避免直接并发遍历数据 map。

本面板用于本地学习展示。`EXPIREAT` 沿用项目的日期字符串格式，`SET` 等返回值也保留项目现有行为。通过外部 `redis-cli` 执行的命令可影响存储快照，但不会出现在页面命令记录中。
